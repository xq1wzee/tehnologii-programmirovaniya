# Лабораторная работа №2 - Основы ООП

## Цель работы

Изучить основные принципы объектно-ориентированного программирования и применить их при разработке простой модели игровой системы.

## Описание работы

В ходе лабораторной работы реализована иерархия классов для пошаговой стратегической игры.

Программа описывает игровые объекты, юнитов и постройки, а также их основные возможности: перемещение, атаку и получение урона.

## Структура проекта

Исходный код программы находится в директории `src/`.

Основные файлы:

- `game_object.py` - базовый класс игровых объектов;
- `unit.py` - класс игрового юнита;
- `attacker.py` - описание возможности атаковать;
- `moveable.py` - описание возможности перемещаться;
- `archer.py` - класс лучника;
- `building.py` - базовый класс построек;
- `fort.py` - класс крепости;
- `mobile_house.py` - класс мобильного дома;
- `main.py` - запуск и проверка программы.

## Основные возможности

- Создание игровых объектов с уникальными идентификаторами.
- Хранение имени и координат объектов.
- Контроль здоровья юнитов.
- Получение урона и проверка состояния юнита.
- Атака противника лучником.
- Атака противника крепостью.
- Перемещение лучника и мобильного дома.
- Проверка состояния построек.

## Используемые принципы ООП

В программе применяются:

- **Инкапсуляция** - данные объектов хранятся внутри классов, доступ к ним осуществляется через методы.
- **Наследование** - специализированные классы получают общие свойства и методы базовых классов.
- **Полиморфизм** - объекты используют общие интерфейсы для выполнения различных действий.
- **Абстракция** - отдельные возможности объектов описываются с помощью абстрактных классов.

## Проверка работы

Для проверки программы используется файл `main.py`.

В нём создаются игровые объекты, выполняются атаки, проверяется здоровье юнитов и демонстрируется перемещение объектов.

## Результат

В результате лабораторной работы создана программа с иерархией игровых объектов, демонстрирующая применение основных принципов ООП на языке Python.

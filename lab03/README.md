# Лабораторная работа №3 - Порождающие паттерны проектирования

## Цель работы

Изучить порождающие паттерны проектирования и применить их для организации создания объектов на языке Python.

## Описание работы

В ходе лабораторной работы реализованы четыре порождающих паттерна проектирования:

- Singleton (Одиночка);
- Factory Method (Фабричный метод);
- Abstract Factory (Абстрактная фабрика);
- Builder (Строитель).

Для каждого паттерна разработан отдельный пример, демонстрирующий его назначение и принцип работы.

## Структура проекта

Исходный код программы находится в директории `lab03/src/`.

Основные файлы и директории:

- `src/main.py` - главный файл для запуска всех демонстраций;
- `src/singleton/` - реализация паттерна Singleton:
  - `settings.py` - класс настроек приложения с единственным экземпляром;
  - `demo.py` - демонстрация работы Singleton;
- `src/factory_method/` - реализация паттерна Factory Method:
  - `exporters.py` - интерфейс экспортёра и его реализации;
  - `creators.py` - базовый создатель и конкретные создатели;
  - `demo.py` - демонстрация экспорта документов;
- `src/abstract_factory/` - реализация паттерна Abstract Factory:
  - `products.py` - интерфейсы и конкретные виды мебели;
  - `factories.py` - абстрактная фабрика и конкретные фабрики;
  - `room.py` - класс комнаты, использующий мебель;
  - `demo.py` - демонстрация работы фабрик;
- `src/builder/` - реализация паттерна Builder:
  - `computer.py` - класс готового компьютера;
  - `computer_builder.py` - класс для пошаговой сборки компьютера;
  - `demo.py` - демонстрация сборки компьютера.

## Реализованные паттерны

### Singleton (Одиночка)

Паттерн гарантирует наличие только одного экземпляра класса.

В программе реализован класс `AppSettings`, который хранит настройки приложения. При повторном создании объекта возвращается тот же экземпляр. Для контроля создания используется метод `__new__`.

### Factory Method (Фабричный метод)

Паттерн определяет интерфейс создания объекта, позволяя подклассам выбирать его конкретную реализацию.

В программе реализован экспорт документов в форматы PDF и HTML. Базовый класс `ExporterCreator` определяет фабричный метод `create_exporter()`, а классы `PdfCreator` и `HtmlCreator` создают соответствующие экспортёры.

### Abstract Factory (Абстрактная фабрика)

Паттерн предоставляет интерфейс для создания семейств взаимосвязанных объектов.

В программе реализованы два семейства мебели: современная и классическая. Фабрики `ModernFurnitureFactory` и `ClassicFurnitureFactory` создают соответствующие стулья и диваны. Класс `Room` работает с абстрактным интерфейсом фабрики.

### Builder (Строитель)

Паттерн позволяет создавать сложные объекты поэтапно, разделяя процесс создания на отдельные шаги.

В программе реализован класс `ComputerBuilder`, с помощью которого можно последовательно задать процессор, оперативную память, накопитель и видеокарту. Метод `build()` создаёт готовый объект `Computer`.

## Запуск программы

Для работы необходим Python 3.10 или новее.

Дополнительные библиотеки устанавливать не требуется.

Для запуска отдельных демонстраций в PyCharm созданы конфигурации запуска с типом «Имя модуля»:

- `singleton.demo` - запуск Singleton;
- `factory_method.demo` - запуск Factory Method;
- `abstract_factory.demo` - запуск Abstract Factory;
- `builder.demo` - запуск Builder.

В качестве рабочей директории используется `lab03/src/`. Каждую демонстрацию можно запустить отдельно с помощью кнопки Run в PyCharm.

Для запуска всех демонстраций через главный файл `main.py` используется команда:

```bash
python main.py
```

Команду необходимо выполнять из директории `lab03/src/`.

## Результат

В результате лабораторной работы реализованы четыре порождающих паттерна проектирования на языке Python. Программа демонстрирует создание единственного экземпляра класса, создание объектов с помощью фабричного метода, формирование семейств взаимосвязанных объектов и пошаговую сборку сложного объекта.

# Лабораторная работа № 6. Тестирование программного обеспечения

## Цель работы

Изучить основы тестирования программного обеспечения, научиться создавать автоматизированные юнит-тесты на Python и использовать мокирование для проверки взаимодействия между объектами.

## Описание работы

В ходе лабораторной работы реализован класс `BankAccount`, моделирующий банковский счёт.

Класс поддерживает следующие операции:
- создание банковского счёта;
- пополнение баланса;
- снятие денежных средств;
- получение текущего баланса;
- проверку корректности вводимых сумм;
- проверку достаточности средств при снятии.

Также реализован класс `TransactionLogger`, предназначенный для регистрации операций по счёту.

Для проверки работы программы написаны автоматизированные юнит-тесты с использованием библиотек `unittest` и `unittest.mock`.

## Реализованные классы

### BankAccount

Основной класс банковского счёта.

Основные методы:
- `__init__(accountNumber, balance)` — создание счёта с начальным балансом.
- `deposit(amount)` — пополнение счёта.
- `withdraw(amount)` — снятие денежных средств.
- `getBalance()` — получение текущего баланса.
- `set_logger(logger)` — установка объекта для регистрации операций.

При попытке пополнить или снять нулевую либо отрицательную сумму возникает исключение `ValueError`.

Если сумма снятия превышает текущий баланс, возникает исключение `ValueError` с сообщением `Insufficient funds`.

### TransactionLogger

Класс для регистрации операций по банковскому счёту.

Используется для демонстрации взаимодействия между объектами и мокирования при тестировании.

## Тестирование

Для тестирования используется стандартная библиотека Python `unittest`.

Для мокирования применяется `MagicMock` из библиотеки `unittest.mock`. С его помощью заменяется реальный объект логгера, что позволяет проверить вызовы метода `log_transaction()` без использования настоящего логгера.

Реализовано 13 тестов, проверяющих:

1. Создание счёта с корректным начальным балансом.
2. Создание счёта с балансом по умолчанию.
3. Создание счёта с отрицательным балансом.
4. Успешное пополнение счёта.
5. Пополнение счёта нулевой суммой.
6. Пополнение счёта отрицательной суммой.
7. Успешное снятие денежных средств.
8. Снятие всей доступной суммы.
9. Попытку снятия суммы, превышающей баланс.
10. Снятие нулевой суммы.
11. Снятие отрицательной суммы.
12. Проверку баланса после нескольких операций.
13. Проверку отсутствия вызова логгера при некорректной операции.

## Запуск программы и тестов

Тестирование производится через терминал.

1. Открыть терминал в корневой папке проекта.
2. Перейти в папку лабораторной работы:

```bash
cd lab06
```

3. Запустить автоматизированные тесты:

```bash
python -m unittest discover -s tests -v
```

После запуска в терминале отображается результат выполнения
